# Buscador de Repositórios GitHub

Uma aplicação frontend desenvolvida em TypeScript puro (Vanilla) seguindo a arquitetura MVC. O projeto consome a API pública do GitHub para buscar repositórios e permite o gerenciamento de favoritos e itens visualizados através do `localStorage`.

##  Funcionalidades
- Busca de repositórios pelo nome.
- Listagem com nome e link direto para o GitHub.
- Opção de favoritar e desfavoritar repositórios (salvos localmente).
- Marcação de repositórios como "Visualizado".
- Ordenação alfabética e por data de criação.

##  Tecnologias Utilizadas
- HTML5 & CSS3
- TypeScript
- Vite
- API REST do GitHub

##  Como executar o projeto

1. Certifique-se de ter o Node.js instalado na sua máquina.
2. Clone este repositório:
   \`\`\`bash
   git clone <URL_DO_SEU_REPOSITORIO>
   \`\`\`
3. Acesse a pasta do projeto:
   \`\`\`bash
   cd buscador-repositorios
   \`\`\`
4. Instale as dependências:
   \`\`\`bash
   npm install
   \`\`\`
5. Inicie o servidor de desenvolvimento:
   \`\`\`bash
   npm run dev
   \`\`\`
6. Abra o link gerado no terminal (geralmente `http://localhost:5173`) no seu navegador.
